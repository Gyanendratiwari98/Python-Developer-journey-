# 🚀 Mini Project — Number Analysis Program

The main project for Day 3 is a **Number Analysis Program**.

The program accepts multiple numbers from the user and analyzes them.

### Features

- Count total numbers
- Count positive numbers
- Count negative numbers
- Count zeros
- Count even numbers
- Count odd numbers
- Calculate total sum
- Calculate average

### Example

```text
How many numbers do you want to enter? 5

Enter number 1: 10
Enter number 2: -5
Enter number 3: 7
Enter number 4: 0
Enter number 5: 12

------ ANALYSIS ------

Total numbers: 5
Positive numbers: 3
Negative numbers: 1
Zero: 1

Even numbers: 3
Odd numbers: 2

Sum: 24
Average: 4.8
```

# 🧠 What I Learned

Today I learned how loops allow a program to repeat a block of code efficiently.

I learned that:

- `for` is useful when iterating over a known sequence or range.
- `while` is useful when repetition depends on a condition.
- `range()` generates a sequence of numbers.
- `break` completely stops a loop.
- `continue` skips the current iteration.
- Nested loops allow one loop to run inside another.
- Loops become more powerful when combined with `if/elif/else`.
