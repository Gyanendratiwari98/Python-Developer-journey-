🐍 Python Day 2 — Conditions & Decision Making

📌 Overview

Day 2 of my Python learning journey focused on conditional statements and decision-making.

The goal was to learn how Python evaluates conditions and executes different blocks of code based on the result.

💻 Practice Programs

1. Positive, Negative or Zero

Takes a number from the user and determines whether it is positive, negative, or zero.

2. Even or Odd

Uses the modulo "%" operator to determine whether a number is even or odd.

3. Age Eligibility

Checks whether a person is eligible based on their age.

4. Largest of Two Numbers

Compares two numbers and determines which one is larger.

5. Largest of Three Numbers

Compares three numbers and finds the largest without using Python's built-in "max()" function.

6. Student Grade Calculator

Takes marks from multiple subjects, calculates the average, and assigns a grade based on the result.

7. Student Eligibility Checker

Checks both marks and attendance to determine whether a student is eligible for an examination.

---

🚀 Mini Project — Student Grade & Eligibility Calculator

The mini project takes:

- Student name
- Python marks
- SQL marks
- Mathematics marks
- Attendance percentage

It then:

1. Calculates the average marks.
2. Assigns a grade.
3. Determines PASS/FAIL.
4. Checks attendance.
5. Determines examination eligibility.

Example Output

Student: Gyanendra
Average: 78.5
Grade: B
Result: PASS
Exam Eligibility: Eligible

🧠 Key Learning

Today I learned how to make Python programs take decisions based on conditions.

I also learned how logical operators such as "and", "or", and "not" can combine multiple conditions.

These concepts are important because they are used throughout real-world applications, APIs, authentication systems, validation, and backend development.
