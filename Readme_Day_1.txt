## 💻 Practice Programs

### 1. Personal Information

A program that takes basic information from the user and displays it.

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))

print(f"My name is {name} and I am {age} years old.")
```

### 2. Basic Calculator

Takes two numbers and calculates:

- Sum
- Difference
- Product
- Division

### 3. Age Calculator

Takes the user's current age and calculates their age after 10 years.

### 4. Celsius to Fahrenheit

Converts temperature from Celsius to Fahrenheit.

**Formula:**

```text
F = (C × 9/5) + 32
```

### 5. Rectangle Area Calculator

Calculates the area of a rectangle.

**Formula:**

```text
Area = Length × Width
```

### 6. Salary Calculator

Calculates:

- Monthly salary
- Annual salary
- Salary after a 10% increase

### 7. Personal Information + Salary Calculator

A mini project that combines the concepts learned during Day 1.

The program asks for:

- Name
- Age
- Monthly salary
- Monthly expenses

Then calculates:

- Annual salary
- Annual expenses
- Annual savings

## 🧠 Important Concepts

### Variables

```python
name = "Gyanendra"
age = 22
height = 187.5
is_student = True
```

### User Input

```python
name = input("Enter your name: ")
```

### Type Conversion

```python
age = int(input("Enter your age: "))
salary = float(input("Enter your salary: "))
```

### Arithmetic Operators

```python
a + b
a - b
a * b
a / b
a // b
a % b
```

### String Formatting

```python
print(f"My name is {name} and I am {age} years old.")
```
